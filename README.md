Dispositif Interactif XR (Version Individuelle)


Présentation du projet
l
Ce dépôt contient ma version personnelle déveoppée dans le cadre du BUT MMI de l'IUT du Limousin. Après une phase de conception en groupe, ce projet "Solo" explore une approche différente centrée sur une expérience utilisateur unique en Réalité Étendue (XR).

L'objectif est de répondre à la problématique : Comment placer l'utilisateur au centre d'un dispositif immersif ?

Technologies exploitées

A-Frame : Pour la structure de la scène 3D via des balises HTML.

WebXR API : Pour l'accès aux capteurs de mouvement et aux caméras du casque.

JavaScript : Pour la logique d'interaction dynamique et la manipulation des entités.

Organisation & Livrables

Ce projet suit le calendrier de la SAE (Janvier - Mars 2026) :

Phase 1 : Travail de base en trinôme (Livrables 1 à 3).

Phase 2 : Améliorations individuelles et refonte (Livrables 4 et 5).

Note importante : Ce code est une version évoluée et personnelle. Il démontre ma capacité à intégrer des interactions riches et à produire des animations 3D de qualité professionnelle.

Comment tester mon application ?
Hébergement : Le projet est accessible via GitHub Pages.

Accès : Ouvrez le navigateur du casque Meta Quest 3.

Lancement : Entrez l'URL de ce dépôt et cliquez sur "Enter VR" ou "Enter AR" pour démarrer l'expérience.
